# Expense Claims — frontend

Vue 3 client for the Expense Claims API. Setup, pages, design notes, Docker and deployment are documented in the [root README](../README.md#frontend).

```sh
cp .env.example .env   # set VITE_API_URL=http://localhost:4000
npm install
npm run dev            # http://localhost:5173
npm run type-check && npm run lint && npm run build
```

Recommended editor setup: VS Code with the [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar) extension, and the Vue.js devtools browser extension.
